💡 ¿Para quién es esta guía?

Esta guía está diseñada para cualquier persona que quiera tener su propio asistente de IA, sin importar su nivel técnico. Explicamos todo paso a paso, con lenguaje sencillo y ejemplos claros.

01. ¿Qué es Clawdbot?

Clawdbot es un programa que te permite tener tu propio asistente de inteligencia artificial, similar a ChatGPT, pero con superpoderes adicionales:

🧠💬📱

Clawdbot conecta la IA más avanzada con tus herramientas del día a día

¿Qué puede hacer?

  • Responder mensajes de WhatsApp, Telegram o Signal automáticamente
  • Leer y escribir archivos en tu computadora
  • Ejecutar tareas programadas (como enviarte recordatorios)
  • Conectarse con servicios como Google Calendar, Monday.com, etc.
  • Mantener memoria de conversaciones anteriores
  • Trabajar 24/7 sin que tengas que estar presente
✨ La magia de Clawdbot

A diferencia de usar ChatGPT en el navegador, Clawdbot vive en tu computadora o servidor, lo que significa que puede hacer cosas por ti incluso cuando no estás frente a la pantalla.

¿Cuánto cuesta?

El software Clawdbot es gratuito. Solo pagas por el uso de la IA (como Claude de Anthropic), que típicamente cuesta entre $5-20 USD al mes dependiendo de cuánto lo uses.

02. Requisitos Previos

Antes de comenzar, necesitas tener algunas cosas listas:

🔑 Una API Key de Anthropic

Esta es la "llave" que permite a Clawdbot usar la inteligencia artificial de Claude. Es como una contraseña que identifica tu cuenta.

1

Crear cuenta en Anthropic

Ve a console.anthropic.com y crea una cuenta gratuita.

2

Generar tu API Key

En el menú, busca "API Keys" y haz clic en "Create Key". Copia la clave y guárdala en un lugar seguro.

3

Agregar crédito

Agrega un método de pago y carga al menos $5 USD para comenzar.

⚠️ Importante

Nunca compartas tu API Key. Es como una contraseña. Si alguien la tiene, puede usar tu cuenta y generarte cargos.

03. Instalación en tu Computadora

Esta es la forma más sencilla de comenzar. Instalarás Clawdbot directamente en tu Mac, PC con Windows, o computadora con Linux.

🍎
macOS
Mac con chip Intel o Apple Silicon
🪟
Windows
Windows 10 o superior
🐧
Linux
Ubuntu, Debian, etc.

Paso 1: Instalar Node.js

Node.js es el motor que permite ejecutar Clawdbot. Es gratuito y fácil de instalar.

1

Descargar Node.js

Ve a nodejs.org y descarga la versión "LTS" (la más estable). Haz clic en el botón verde "LTS Recommended".

2

Ejecutar el instalador

Abre el archivo descargado y sigue las instrucciones. Acepta todas las opciones por defecto.

3

Verificar la instalación

Abre la Terminal (Mac/Linux) o PowerShell (Windows) y escribe:

node --version

Deberías ver algo como v22.0.0 (el número puede variar).

Paso 2: Instalar Clawdbot

Con Node.js instalado, ahora puedes instalar Clawdbot con un solo comando:

# Ejecuta este comando en la Terminal o PowerShell
npm install -g clawdbot
💡 ¿Qué significa este comando?

npm = Node Package Manager (gestor de paquetes)
install -g = instalar de forma global (disponible en todo el sistema)
clawdbot = el nombre del programa a instalar

Paso 3: Configuración Inicial

1

Iniciar el asistente de configuración

clawdbot setup
2

Ingresar tu API Key

Cuando te lo pida, pega la API Key de Anthropic que obtuviste antes.

3

Elegir tu modelo

Selecciona Claude Sonnet para un balance entre costo y capacidad, o Claude Opus si quieres el más potente.

Paso 4: Iniciar Clawdbot

# Inicia el servicio
clawdbot start
🎉 ¡Listo!

Si ves el mensaje "Gateway started", tu asistente ya está corriendo. Puedes probarlo abriendo http://localhost:18788 en tu navegador.

04. Instalación en la Nube

Si quieres que tu asistente esté disponible 24/7 sin tener tu computadora encendida, puedes instalarlo en un servidor en la nube.

  • Fácil de configurar
  • Solo funciona cuando está encendida
  • Ideal para probar

  • Funciona 24/7
  • Ideal para uso serio

Instalación en Railway (Recomendado)

Railway es la opción más sencilla para principiantes.

1

Crear cuenta en Railway

Ve a railway.app y crea una cuenta (puedes usar tu cuenta de GitHub).

2

Crear nuevo proyecto

Haz clic en "New Project" → "Empty Project"

3

Agregar un servicio

Clic en "Add Service" → "Docker Image" y escribe:

ghcr.io/clawdbot/clawdbot:latest
4

Configurar variables de entorno

En la pestaña "Variables", agrega:

ANTHROPIC_API_KEY = tu_api_key_aqui
DEFAULT_MODEL = claude-sonnet-4-20250514
5

Generar dominio

En "Settings" → "Networking" → "Generate Domain". Esto te dará una URL como tu-proyecto.up.railway.app

6

Desplegar

Haz clic en "Deploy" y espera unos minutos. ¡Tu asistente estará en línea!

✅ Verificar instalación

Visita tu-proyecto.up.railway.app en tu navegador. Deberías ver la interfaz de Clawdbot.

Instalación con Docker (Alternativa)

Si prefieres usar Docker en cualquier servidor:

# Descargar e iniciar Clawdbot
docker run -d \
-e ANTHROPIC_API_KEY=tu_api_key \
-p 18788:18788 \
ghcr.io/clawdbot/clawdbot:latest

05. Configuración Inicial

Una vez instalado, Clawdbot necesita algunos ajustes para funcionar como tú quieras.

El Panel de Control

Accede al panel de control en tu navegador:

# Si instalaste localmente:
http://localhost:18788

# Si instalaste en la nube:
https://tu-dominio.railway.app

Configuraciones Importantes

1

Crear un Token de Seguridad

En "Settings" → "Gateway" → "Control UI Token", genera un token. Este protege tu panel de accesos no autorizados.

2

Configurar la Personalidad

Edita el archivo SOUL.md para definir cómo quieres que se comporte tu asistente. ¿Formal? ¿Amigable? ¿Directo?

3

Crear tu Workspace

El workspace es una carpeta donde tu asistente guardará sus archivos y memoria. Por defecto está en ~/clawd.

📁 Archivos importantes del Workspace

SOUL.md - Personalidad del asistente
USER.md - Información sobre ti
MEMORY.md - Memoria a largo plazo
TOOLS.md - Configuraciones técnicas

06. Conectar con WhatsApp

Una de las funciones más útiles de Clawdbot es poder chatear con tu asistente directamente desde WhatsApp.

⚠️ Nota importante

Clawdbot usa WhatsApp Web, lo que significa que tu cuenta de WhatsApp estará conectada al servicio. Los mensajes que envíes al asistente saldrán de tu número.

Pasos para Conectar

1

Abrir el Panel de Control

Ve a la sección "Channels" → "WhatsApp"

2

Generar código QR

Haz clic en "Connect" para generar el código QR

3

Escanear con WhatsApp

En tu teléfono, abre WhatsApp → Configuración → Dispositivos vinculados → Vincular dispositivo → Escanea el código QR

4

Configurar tu número

En la configuración, agrega tu número de teléfono como "owner" para que el asistente sepa que eres tú el dueño.

🎉 ¡Conectado!

Ahora puedes enviar un mensaje a tu propio número de WhatsApp y tu asistente te responderá. También puedes agregarlo a grupos.
